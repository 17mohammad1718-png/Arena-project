# نقشه راه پس از فاز ۴ — فراتر از بابلکنار

> این سند مکمل `phase-4-plan.md` است و برای اینکه با لیمیت روزانه به مشکل نخوریم، همین الان در شاخه `arena/01a00fe9-arena-project` تثبیت می‌شود.
> مرجع اصلی: [برنامه محصول](product-plan.md) — بخش Product scope (۱. اقامتگاه مالک → ۶. کل ایران)

## الان کجاییم؟

- **فاز ۱ ✅** — نمونه اولیه با داده دمو + سوئیچ به داده واقعی
- **فاز ۲ ✅** — داده عملیاتی میزبان (هزینه/رزرو/بلاک/ایمپورت/آرشیو) در SQLite
- **فاز ۳ ✅** — هوش بازار (مجموعه رقبا، تاریخچه قیمت، روند عرضه/اشغال، هشدار روزانه، تازگی داده)
- **فاز ۴ 🚧 پلن آماده** — تحلیل پیشرفته (تعطیلات ایرانی + قیمت داده‌محور + گزارش هفتگی + چنداقامتگاهی + آب‌وهوا) → `docs/phase-4-plan.md`

بعد از فاز ۴، محصول از «ابزار یک کلبه در بابلکنار» به «پلتفرم قابل تعمیم» تبدیل می‌شود.

## فاز ۵ — مقیاس جغرافیایی (بابل → مازندران → شمال)

**هدف:** همان داشبورد بدون بازنویسی برای ۱۰۰ → ۲۰۰۰ اقامتگاه کار کند.

- سوییپ سراسری `top_rooms_sweep.json` (۲۸۷۰ اتاق) همین الان موجود است ولی فقط بابلکنار فیلتر می‌شود.
- کار: پارتیشن‌بندی داده بر اساس `city_id`/`province`، فیلتر استان/شهر در `/competitors` و `/market`، کش منطقه‌ای `getDataset(region)`.
- چالش: حجم ~۱۰MB → ~۵۰MB؛ lazy-load + فشرده‌سازی JSON یا مهاجرت به SQLite/PostgreSQL برای دیتاست بازار.
- خروجی پذیرش: انتخاب «مازندران» در هدر، همه KPIها و نقشه قیمت-امتیاز را برای همان استان بسازد.

## فاز ۶ — نقشه و تجربه میدانی

- نقشه تعاملی رقبا (Leaflet/MapLibre) با خوشه‌بندی، فیلتر فاصله شعاعی واقعی (نه فقط روستا).
- عکس‌های آگهی + لینک مستقیم جاجیگا + فاصله هوایی دقیق با `haversineKm` (همین الان در `analytics.ts` هست).
- مُد موبایل میدانی: میزبان در بازدید کلبه، روی نقشه رقبای ۵۰۰ متری را ببیند.

## فاز ۷ — استقرار چندکاربره و امن

- PostgreSQL به‌جای SQLite، احراز هویت (NextAuth)، نقش‌ها (مالک/همکار/تحلیل‌گر).
- جداسازی داده میزبان per-user، بکاپ خودکار، رمزنگاری `var/mizbanyar.db` فعلی.
- این فاز قبل از هر انتشار عمومی اجباری است — تا قبلش اپ تک‌کاربره محلی می‌ماند (اصل فاز ۲).

## فاز ۸ — هوشمندی عمیق‌تر (وقتی داده کافی شد)

- مدل رگرسیون ساده برای پیشنهاد قیمت (ورودی: فصل، تعطیلات، آخرهفته، امتیاز، اشغال بازار) — جایگزین ضرایب توصیفی فاز ۴ فقط وقتی ≥ ۲۰ برش آرشیو داریم.
- هشدار پیش‌بینی‌محور: «با روند فعلی، آخرهفته بعد ۷۰٪ پر می‌شود — قیمت را +۱۲٪ ببر».
- همبستگی‌های بیشتر: آب‌وهوا (فاز ۴ P5)، رویدادهای محلی (کنسرت، تعطیلات مدارس)، قیمت سوخت.
