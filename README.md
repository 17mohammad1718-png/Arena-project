# میزبان‌یار (MizbanYar)

داشبورد فارسی و راست‌به‌چپ برای تحلیل عملکرد، قیمت‌گذاری و رقبای اقامتگاه‌های اجاره کوتاه‌مدت،
با شروع از یک اقامتگاه در بابلکنار مازندران.

> A Persian RTL analytics dashboard for Jajiga hosts — performance, pricing intelligence and
> competitor benchmarking, starting from one residence in Babolkenar, Mazandaran.

## وضعیت پروژه

**فاز ۱ کامل شد و داشبورد روی داده واقعی اجرا می‌شود.**

هیچ داده نمایشی یا ساختگی در برنامه باقی نمانده است. همه اعداد مستقیماً از فایل‌های واقعی
پوشه `data/` خوانده می‌شوند: ۱۰۰ اقامتگاه فعال بابلکنار، ۳۵ تقویم رصدشده، درآمد محقق‌شده
منطقه و نظرات مهمانان اقامتگاه پایه (جاجیگا ۳۲۹۷۵۸۵).

## اجرا

```bash
npm install
npm run dev
```

سپس <http://localhost:3000> را باز کنید.

## دیتاست واقعی

پوشه `data/` حاوی **داده واقعی و تأییدشده جاجیگا** است که توسط پایپ‌لاین مالک پروژه
(Hermes / jajiga-tracker) جمع‌آوری شده: فاکتورهای قیمت ۱۰۴ کلبه بابلکنار، سوییپ سراسری
۲۸۷۰ اقامتگاه ایران، تقویم رزرو هر اتاق (radar)، نظرات مهمانان، تاریخچه عرضه و درآمد
اقامتگاه خود مالک.

**پیش از استفاده از هر فایل، حتماً [`docs/DATA-GUIDE.md`](docs/DATA-GUIDE.md) را بخوانید** —
معنای دقیق فیلدها، هشدارهای مهم و روش به‌روزرسانی در آن مستند شده است.

> ⚠️ خودتان از جاجیگا اسکرپ نکنید. برای داده تازه‌تر، از طریق issue درخواست بدهید تا
> پایپ‌لاین موجود آن را رفرش کند.

### نکات حیاتی داده (از DATA-GUIDE)

- امتیاز نمایش‌داده‌شده جاجیگا میانگین **۱۲ ماه اخیر** است، نه کل تاریخچه.
- API نظرات حدود **۱۰٪ کمتر** از عدد روی کارت برمی‌گرداند؛ هر دو عدد باید نشان داده شود.
- `is_unavailable` یعنی **رزرو یا بلاک دستی میزبان** — بلاک‌ها در `manual-blocks.json`
  مشخص شده‌اند و باید حالت جدا با درآمد صفر باشند.
- همیشه `min_price` (نرخ پایه) مبنا باشد، نه قیمت تخفیف‌خورده کارت.
- همه مبالغ به تومان و همه تاریخ‌ها در JSON میلادی‌اند؛ UI باید شمسی نشان دهد.

## معماری

```
src/
├── app/                      هشت صفحه Next.js (App Router)
├── components/               شل اپ، کارت‌ها، نمودارها و جدول رقبا
└── lib/
    ├── dates.ts              تقویم جلالی، تعطیلات، تشخیص آخر هفته و فصل تقاضا
    ├── metrics.ts            کمک‌تابع‌های عددی و قالب‌بندی فارسی (بدون منطق دامنه)
    └── jajiga/               لایه اتصال به دیتاست واقعی
        ├── schemas.ts        اسکیمای zod سهل‌گیر برای فایل‌های واقعی
        ├── features.ts       ترجمه کد امکانات و نوع اقامتگاه به فارسی
        ├── load.ts           خواندن فایل‌ها، نرمال‌سازی و ثبت خطاهای بارگذاری
        ├── analytics.ts      تقویم، KPI، شباهت رقبا، جایگاه بازار، درآمد و نظرات
        ├── pricing.ts        شاخص قیمت هر شب از تقویم رقبا و بازه پیشنهادی
        ├── insights.ts       تولید توصیه‌های فارسی قاعده‌محور
        └── dataset.ts        نقطه ورود واحد — getDataset()
```

همه صفحه‌ها فقط `getDataset()` را صدا می‌زنند. این تابع کل دیتاست (حدود ۱۰ مگابایت) را
یک بار در هر پروسه می‌خواند و نتیجه را کش می‌کند.

### تصمیم‌های کلیدی

- **شب مسدود ≠ شب فروش‌نرفته:** `is_unavailable` می‌تواند رزرو یا بلاک دستی باشد. با
  `manual-blocks.json` تفکیک می‌شود و بلاک‌ها از مخرج نرخ اشغال حذف می‌شوند.
- **قیمت مرجع از تقویم واقعی رقبا:** به‌جای یک فرمول ثابت آخر هفته/فصل، میانه نرخ واقعی
  رقبا برای همان تاریخ از فایل‌های `radar/` استخراج می‌شود؛ اثر آخر هفته و فصل از پیش در
  آن هست. فقط شب‌های قابل رزرو رقبا وارد توزیع می‌شوند تا قیمت کهنه شب‌های فروخته‌شده
  نتیجه را منحرف نکند.
- **مجموعه مرجع تطبیقی:** در بابلکنار تقریباً همه آگهی‌ها کلبه‌ای در شعاع چند کیلومتری‌اند،
  پس آستانه ثابت شباهت کار نمی‌کند. به‌جای آن ۲۰ رقیب شبیه‌تر انتخاب می‌شوند.
- **صداقت درباره محدودیت داده:** هر صفحه‌ای که از داده ناقص استفاده می‌کند، محدودیت آن را
  در همان صفحه توضیح می‌دهد؛ شب‌های خارج از بازه رصد کم‌رنگ نمایش داده می‌شوند.

## تعریف شاخص‌ها

- **نرخ اشغال:** شب‌های رزروشده ÷ شب‌های قابل رزرو (بدون شب‌های مسدودشده توسط میزبان)
- **درآمد ناخالص:** مجموع نرخ شب‌های رزروشده **پس از** تخفیف سطح آگهی
- **کمیسیون:** ۱۲٪ از مبلغ پس از تخفیف · **درآمد خالص:** ناخالص − کمیسیون
- **ADR:** درآمد ÷ شب‌های رزروشده · **RevPAN:** درآمد ÷ شب‌های قابل رزرو
- **آخر هفته:** چهارشنبه، پنجشنبه و جمعه
