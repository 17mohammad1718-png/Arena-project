# میزبان‌یار (MizbanYar)

داشبورد فارسی و راست‌به‌چپ برای تحلیل عملکرد، قیمت‌گذاری و رقبای اقامتگاه‌های اجاره کوتاه‌مدت،
با شروع از یک اقامتگاه در بابلکنار مازندران.

> A Persian RTL analytics dashboard for Jajiga hosts — performance, pricing intelligence and
> competitor benchmarking, starting from one residence in Babolkenar, Mazandaran.

## وضعیت پروژه

**فاز ۱ — نمونه اولیه تعاملی: پیاده‌سازی شد.**

داشبورد کامل با داده نمایشی قابل اجراست و به‌محض قرار دادن دیتاست واقعی در پوشه `data/`،
به‌صورت خودکار به داده واقعی سوییچ می‌کند.

## اجرا

```bash
npm install
npm run dev
```

سپس <http://localhost:3000> را باز کنید.

## صفحه‌ها

| مسیر | صفحه | محتوا |
|---|---|---|
| `/` | نمای کلی | KPIهای درآمد، سود خالص، نرخ اشغال، ADR، RevPAN، نرخ لغو و تبدیل + نمودارهای روند |
| `/market` | مقایسه بازار | صدک قیمت، نقشه قیمت–امتیاز، امکانات کم‌داشته و مزیت‌های متمایز |
| `/calendar` | تقویم قیمت | تقویم جلالی با نرخ شما، برآورد بازار، تعطیلات و بازه قیمت پیشنهادی |
| `/competitors` | کاوش رقبا | جدول فیلترشونده با امتیاز شباهت و ساخت مجموعه رقبای دلخواه |
| `/insights` | پیشنهادها | توصیه‌های فارسی قاعده‌محور همراه با مبنای استدلال |
| `/data` | منبع داده | وضعیت بارگذاری هر بخش، هشدارهای اعتبارسنجی و راهنمای ساختار فایل‌ها |

## دیتاست واقعی

پوشه `data/` حاوی **داده واقعی و تأییدشده جاجیگا** است که توسط پایپ‌لاین مالک پروژه
(Hermes / jajiga-tracker) جمع‌آوری شده: فاکتورهای قیمت ۱۰۴ کلبه بابلکنار، سوییپ سراسری
۲۸۷۰ اقامتگاه ایران، تقویم رزرو هر اتاق (radar)، نظرات مهمانان، تاریخچه عرضه و درآمد
اقامتگاه خود مالک.

**پیش از استفاده از هر فایل، حتماً [`docs/DATA-GUIDE.md`](docs/DATA-GUIDE.md) را بخوانید** —
معنای دقیق فیلدها، هشدارهای مهم و روش به‌روزرسانی در آن مستند شده است.

> ⚠️ خودتان از جاجیگا اسکرپ نکنید. برای داده تازه‌تر، از طریق issue درخواست بدهید تا
> پایپ‌لاین موجود آن را رفرش کند.

### نکات حیاتی داده (از DATA-GUIDE)

- امتیاز نمایش‌داده‌شده جاجیگا میانگین **۱۲ ماه اخیر** است، نه کل تاریخچه.
- API نظرات حدود **۱۰٪ کمتر** از عدد روی کارت برمی‌گرداند؛ هر دو عدد باید نشان داده شود.
- `is_unavailable` یعنی **رزرو یا بلاک دستی میزبان** — بلاک‌ها در `manual-blocks.json`
  مشخص شده‌اند و باید حالت جدا با درآمد صفر باشند.
- همیشه `min_price` (نرخ پایه) مبنا باشد، نه قیمت تخفیف‌خورده کارت.
- همه مبالغ به تومان و همه تاریخ‌ها در JSON میلادی‌اند؛ UI باید شمسی نشان دهد.

## معماری

```
src/
├── app/                    صفحه‌های Next.js (App Router)
├── components/             شل اپ، کارت‌ها، نمودارها و جدول رقبا
└── lib/
    ├── types.ts            قراردادهای داده + اسکیمای zod
    ├── dates.ts            تبدیل و قالب‌بندی تقویم جلالی، تعطیلات، فصل تقاضا
    ├── metrics.ts          موتور محاسبه KPI، دفتر شب‌به‌شب و بنچمارک بازار
    ├── analytics.ts        پروفایل روزهای هفته، تفکیک هزینه
    ├── pricing.ts          ساخت تقویم قیمت و بازه پیشنهادی
    ├── insights.ts         تولید توصیه‌های فارسی قاعده‌محور
    ├── csv.ts              خواننده CSV و نرمال‌سازی ارقام فارسی
    ├── load-dataset.ts     تشخیص خودکار فایل‌های واقعی + اعتبارسنجی
    └── demo-data.ts        دیتاست نمایشی بابلکنار (تولید قطعی با seed)
```

### تصمیم‌های کلیدی

- **دفتر شب‌به‌شب:** درآمد هر اقامت چندشبه به‌طور یکنواخت روی شب‌هایش پخش می‌شود تا گزارش ماهانه
  هنگام اقامت‌های بین دو ماه پرش نکند.
- **شب مسدود ≠ شب فروش‌نرفته:** شب‌هایی که میزبان دستی بسته، از مخرج نرخ اشغال حذف می‌شوند.
- **تخمین، نه پیش‌بینی:** بسته بودن تقویم رقیب به‌عنوان «برآورد در دسترس نبودن» برچسب می‌خورد،
  نه اشغال قطعی.
- **امتیاز شباهت شفاف:** ترکیب ظرفیت، اتاق، فاصله، نوع اقامتگاه و همپوشانی امکانات — همراه با
  دلیل قابل خواندن برای میزبان.

## تعریف شاخص‌ها

- **نرخ اشغال:** شب‌های رزروشده ÷ شب‌های قابل رزرو (بدون شب‌های مسدودشده توسط میزبان)
- **ADR:** درآمد اقامت ÷ شب‌های رزروشده
- **RevPAN:** درآمد اقامت ÷ شب‌های قابل رزرو
- **سود خالص:** درآمد ناخالص − کارمزد پلتفرم − هزینه‌های ثبت‌شده
- **نرخ تبدیل:** رزروهای قطعی ÷ بازدید آگهی (در صورت وجود داده)
