# ران‌بوک رفرش داده (Refresh Runbook)

> فاز ۳ — N5 · قانون پایه از [DATA-GUIDE](DATA-GUIDE.md):
> **از سمت این ریپو هیچ اسکرپی انجام نمی‌شود.** همه داده‌های `data/` توسط پایپ‌لاین
> جداگانه مالک (Hermes / jajiga-tracker) تولید می‌شوند و این اپ فقط می‌خوانَد.

## چه زمانی رفرش لازم است؟

صفحه **«منبع داده» → کارت «تازگی داده»** سن هر گروه را نشان می‌دهد:

| گروه | فایل‌ها | آستانه کهنگی | چرا مهم است |
|---|---|---|---|
| تقویم رادار | `data/radar/*.json` | ۷ روز | منبع تقویم قیمت، شاخص بازار و بیشتر هشدارها |
| اسنپ‌شات عرضه | `data/snapshots/supply-*.json` | ۷ روز | روند عرضه و هشدار آگهی جدید |
| درآمد منطقه | `data/revenue/*.json` | ۱۰ روز | رتبه‌بندی درآمد و روند محقق‌شده |
| مشخصات اقامتگاه‌ها | `data/pricing-dataset.json` و زیرمجموعه روستاها | ۱۴ روز | پروفایل رقبا، امکانات، نرخ پایه |
| نظرات مهمانان | `data/reviews/*.json` | ۳۰ روز | تحلیل بازخورد |

## مراحل رفرش

1. **درخواست رفرش از پایپ‌لاین** — اجرای اسکریپت‌های fetch در پروژه `jajiga-tracker`
   (سمت مالک). اگر دسترسی نداری، issue باز کن تا مالک اجرا کند.
2. **همگام‌سازی خودکار با `npm run sync`** (روش پیشنهادی):

   ```bash
   npm run sync -- --dry-run   # پیش‌نمایش: چه چیزی تغییر می‌کند (چیزی نمی‌نویسد)
   npm run sync                # آینه‌سازی data/ از jajiga-tracker + آرشیو خودکار
   ```

   این دستور دیتاست‌های تعریف‌شده (در `scripts/sync-data.ts`، جدول SYNC_TARGETS) را از
   پروژهٔ پایپ‌لاین (به‌صورت پیش‌فرض sibling `../jajiga-tracker` — ریشهٔ پروژه، نه
   فقط `data/`؛ با `--source <dir>` یا env `JAJIGA_TRACKER_ROOT` قابل تغییر) می‌آورد:
   فایل‌های جدید/تغییر‌یافته را کپی می‌کند، داخل دایرکتوری‌های مشترک (radar, revenue,
   reviews, snapshots, supply) فایل‌های حذف‌شده از منبع را پاک می‌کند، و مرحلهٔ آرشیو
   (قدم ۳) را هم خودش اجرا می‌کند. فایل‌های خارج از نقشه، `data/tmp/`, `data/pricing/`
   (خام پایپ‌لاین) و `*.local.*` هرگز لمس نمی‌شوند؛ اگر منبعِ بعضی فایل‌ها موقتاً نباشد
   (مثلاً `jajiga_master.json` هنوز ساخته نشده)، نسخهٔ محلی حفظ و اعلام می‌شود.
   خروجی خلاصهٔ `added/updated/removed` می‌دهد؛ با `--quiet` وقتی چیزی تغییر نکرده
   ساکت می‌ماند (مناسب کرون).

   اگر به هر دلیلی دستی جایگزین می‌کنی: خروجی پایپ‌لاین را با همان نام‌ها و ساختار
   قبلی کپی کن. قرارداد فیلدها در [DATA-GUIDE](DATA-GUIDE.md) ثابت است؛ اگر اسکیما
   عوض شده، اول `src/lib/jajiga/schemas.ts` را هماهنگ کن.

3. **آرشیو تاریخچه — حیاتی:**
   (اگر با `npm run sync` آمده باشد این قدم قبلاً خودکار اجرا شده؛ دستی فقط برای
   رفرش‌هایی که خارج از sync کپی شده‌اند لازم است.)

   ```bash
   npm run archive
   ```

   این دستور برش فعلی درآمد محقق‌شده و قیمت‌های رادار را با مهر زمان در
   `var/mizbanyar.db` ذخیره می‌کند. **اگر قبل از جایگزینی فایل‌ها فراموش شد، بعدش هم
   می‌شود زد** — idempotent است و بر اساس `fetched_at` خودِ داده dedup می‌کند.
   هر رفرشِ بدون آرشیو یعنی یک نقطه از نمودارهای روند (تاریخچه قیمت رقبا، جهت اشغال
   بازار، روند درآمد) برای همیشه از دست رفته.

4. **بررسی سلامت:**

   ```bash
   npm test          # تست‌ها روی دیتاست واقعی هم اجرا می‌شوند
   npm run dev       # صفحه «منبع داده» را باز کن
   ```

   - کارت «تازگی داده» باید گروه‌های رفرش‌شده را «تازه» نشان دهد.
   - بخش «خطاهای بارگذاری» نباید مورد جدیدی داشته باشد.

5. **در صورت تغییر بلاک‌های دستی:** بلاک‌ها حالا در خود اپ (تقویم → کلیک روی شب)
   مدیریت می‌شوند و در دیتابیس محلی‌اند؛ `manual-blocks.json` فقط برای seed اولیه بود
   و نیازی به ویرایش دستی آن نیست.

## بکاپ داده میزبان

داده مالکیتی میزبان (هزینه‌ها، رزروها، بلاک‌ها، مجموعه‌های رقیب، یادداشت‌ها، آرشیو)
جدا از `data/` در `var/mizbanyar.db` است و با رفرش دیتاست دست نمی‌خورد. بکاپ:

```bash
npm run db:export             # var/host-data-YYYY-MM-DD.json
npm run db:import -- file.json
```

## خطاهای رایج

| علامت | علت محتمل | راه‌حل |
|---|---|---|
| «فایل یافت نشد» در منبع داده | نام/مسیر فایل عوض شده | نام‌ها را با جدول بالا تطبیق بده |
| ردیف‌های رد شده در بارگذاری | تغییر اسکیمای پایپ‌لاین | `schemas.ts` را به‌روز کن؛ اسکیماها عمداً سهل‌گیرند |
| نمودار روند خالی ماند | `npm run archive` بعد از رفرش زده نشده | همین حالا بزن؛ برش فعلی ثبت می‌شود |
| هشدار تکراری نمی‌آید | هشدارها روزی یک‌بار per rule ثبت می‌شوند | طبیعی است؛ فردا دوباره ارزیابی می‌شود |
